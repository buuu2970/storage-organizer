# RecSort
Windowsの録画を見比べ、内容が完全に同じ動画を整理候補として確認するWebアプリです。録画を外部へ送信せず、元のファイルは変更しません。

## ブラウザで試す
dist/index.html をChromeで開きます。「ファイルを選ぶ」は個別の録画、「フォルダを調べる」は選択したフォルダ以下の動画を調べます。サンプルデータでも比較から最終確認まで操作できます。ページ内で選んだ判断は再読み込みでリセットされます。

## PC全体を調べる
dist/RecSort-PC.zip を展開し、RecSort-PC.exe を起動します。表示された固定ドライブを確認し、Enterを押すと調査を開始します。Ctrl+Cで中止できます。システム・アプリ用フォルダ、リンク、クラウドのプレースホルダー、アクセスできない場所はスキップします。同じサイズの動画だけをSHA-256で照合し、同じ実体へのハードリンクは複数のコピーとして数えません。

調査完了後、結果が既定のブラウザで開きます。結果HTMLは %LOCALAPPDATA%\RecSort\Reports に保存され、ファイル名と保存場所を含みます。実際の削除操作は行いません。

## 調査ツールをビルド
Windows PowerShellから build.ps1 を実行します。Windowsの.NET Framework 4.x C#コンパイラを使い、Web画面を組み込んだ調査ツールをdist/RecSort-PC.zipに生成します。
