## 6. 最終的な構成（統合版。11/09 のブラウザ版追加後）

```
main.py                     起動（既定はブラウザ版。--desktop でデスクトップ版）
storage_organizer/
  webapp.py                 ブラウザ版のサーバー（127.0.0.1 のみ・合言葉・API・録画の再生）
  web_ui/                   ブラウザ版の画面（index.html・app.js・style.css。5画面）
  app.py                    デスクトップ版の起動処理・エラーログ・二重起動の確認
  main_window.py            デスクトップ版の5画面のメインウィンドウ
  organizer.py              デスクトップ版の各画面（ブラウザ版の手本）
  autoscan.py / scanner.py  自動スキャン・除外・リンクとクラウドファイルの判定
  candidates.py             整理候補と理由（重複・短い・黒画面・読み込み失敗・無音・類似）
  similar.py                類似録画の判定
  media.py                  FFmpeg の検出・動画情報・場面・音量・SHA-256
  store.py                  JSON 保存・復旧・判断／保護／お気に入り
  trash.py                  移動前の安全確認
  recycle_bin.py            Windows のごみ箱への移動（フェイルクローズ）
  instance_lock.py          二重起動の防止
  player.py / theme.py      再生・デザイン
tests/                      自動テスト（ダミーファイルのみ使用）
tools/recycle_bin_live_test.py  ごみ箱の実機試験（ダミーファイル）
docs/presentation/          発表資料
```
