# ストレージ整理支援アプリ（最小版：フォルダ容量調査）

選択したフォルダをサブフォルダまでスキャンし、ファイルを容量順・更新日時順に一覧表示する Windows 向けデスクトップアプリです。
現在の段階は **調査のみ** で、ファイルの変更・削除は一切行いません。

## 動作環境

- Windows 10 / 11
- Python 3.12 以上（3.12 未満ではジャンクション判定が予備的な方法になります）

## インストール

コマンドプロンプトまたは PowerShell で、このフォルダに移動してから実行します。

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

PowerShell で `activate` が拒否される場合は、`.venv\Scripts\activate.bat` をコマンドプロンプトで実行するか、
`.venv\Scripts\python.exe -m pip install -r requirements.txt` のように仮想環境の Python を直接使ってください。

## 起動

```
python main.py
```

1. 「フォルダを選択…」でフォルダを選ぶ
2. 「スキャン開始」を押す
3. 完了すると容量の大きい順に並びます。列見出しをクリックすると並び替えられます

## 動作確認用のサンプルフォルダ

```
python tools/make_sample_folder.py C:\Users\<ユーザー名>\Desktop\sample_scan_folder
```

約 13.5 MB・12 ファイルの小さなフォルダを新しく作ります（作成先が既にある場合は中止します）。

## テスト

```
python -m unittest discover -s tests -v
```

## 今回の範囲と仕様

- 表示項目：ファイル名、サイズ、種類（拡張子で判定）、最終更新日時、保存場所
- サイズは **ファイルサイズ（st_size）の合計** です。圧縮・クラウドのみのファイルなどがあると、実際のディスク使用量とは一致しません
- スキャンは別スレッドで行い、約 0.2 秒ごとにまとめて画面へ反映します
- 総件数は事前に分からないため、進捗は割合（%）ではなく「動作中の表示・件数・現在のフォルダ」で示します
- シンボリックリンクとジャンクションはたどらず、件数だけ表示します
- アクセスできない場所はスキップし、件数を表示します（集計欄にマウスを乗せると、先頭 20 か所の場所と理由が出ます）
- ファイルの内容は読まず、フォルダ一覧から得られるメタデータだけを使います
- 走査中は並び替えを止め、完了後（またはキャンセル後）に有効になります
- 結果は保存しません（アプリを閉じると消えます）
