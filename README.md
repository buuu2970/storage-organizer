# storage-organizer
Windowsストレージ整理アプリ

PC内の動画を解析して、削除してよさそうな動画を「削除推奨度」つきで一覧表示します。
ブラウザ画面でサムネイル・再生・保存場所を確かめながら、チェックした動画をデスクトップの **「削除予定」フォルダへ移動** します。

> **このアプリは動画を削除しません。** 最終的な削除 (ごみ箱への移動) は、利用者が自分の手で行います。

## 必要なもの
- Windows 10 / 11
- Python 3.9 以上 (追加ライブラリ不要)
- ffmpeg … `winget install Gyan.FFmpeg`

## 使い方
`ストレージ整理.bat` をダブルクリック (または `py -m storage_organizer`) → ブラウザに画面が開きます。

1. 調べるフォルダを選ぶ (ビデオ・デスクトップ・ダウンロード等が初期登録済み。`D:\録画` なども追加可)
2. 「スキャン開始」を押す
3. サムネイルをクリックで再生 / 「場所を開く」でエクスプローラー表示して中身を確認
4. 消したい動画の「削除」にチェックを入れる
5. スキャン後に「削除予定に移動」に変わったボタンを押す → 確認画面で実行
   - デスクトップに「削除予定」フォルダが作られ (既にあればそのまま使用)、選んだ動画がそこへ移動します
   - 同じ名前の動画がある場合は `名前_1.mp4` のように番号を付け、上書きはしません
6. **最後の削除は自分の手で行います**
   1. 画面の「削除予定フォルダを開く」(またはデスクトップの「削除予定」フォルダ) を開く
   2. 中身を確認し、本当に不要な動画だけを選んで、右クリック →「削除」(またはDeleteキー) でごみ箱へ移動する
   3. 残しておきたい動画があれば、元の場所に戻す (元の場所は `移動履歴.csv` で確認できます)
   4. ごみ箱を空にすると完全に削除されます (空にするまではごみ箱から元に戻せます)

| 操作 | アプリ | 利用者 |
|------|:-----:|:-----:|
| デスクトップに「削除予定」フォルダを作る | ✅ | ✅ |
| 選んだ動画を「削除予定」フォルダへ移動する | ✅ | ✅ |
| 「削除予定」の動画をごみ箱へ移動・削除する | ❌ (機能なし) | ✅ |
| ごみ箱を空にする | ❌ (機能なし) | ✅ |

## 削除推奨度の基準
| 推奨度 | 理由 |
|--------|------|
| 高 | 10秒未満 / 重複 (同じ内容のコピー。更新日時が古い方を元として残す) / 壊れたファイル / 画質と音声の両方に問題 |
| 中 | 画質が粗い (短辺720px未満・15fps未満・映像のぼやけ) / 音声が不明瞭 (音声なし・無音・ほぼ無音・小音量・音割れ・低音質) |
| 低 | 1時間30分以上 (大事な長時間録画の可能性があるので参考扱い) |

基準値は `storage_organizer/video_analyzer.py` の `Thresholds` にまとまっています。

## 安全のための仕組み
- アプリに許可している操作は「削除予定フォルダの作成」と「そこへの動画の移動」だけです。削除・ごみ箱へ移す機能は持っていません (テストでも確認しています)
- 移動するのはチェックした動画だけです。自動では1本も動かしません
- 移動履歴 (元の場所 → 移動先) を `%LOCALAPPDATA%\storage-organizer\移動履歴.csv` に記録します
- 「削除予定」フォルダ自体はスキャン対象から外すので、移動済みの動画が再び候補に出ることはありません
- Windows・Program Files・AppData などのシステムフォルダは調べません
- 画面は 127.0.0.1 (自分のPC) からのみ開け、起動ごとの合言葉付きURL以外からの操作は拒否します
- 移動できるのはスキャン結果に含まれるファイルだけです

## コマンドライン版 (レポート / 仕分け)
画面を使わずに CSV レポートを作ったり、理由別フォルダへ仕分けたりできます。

```
py -m storage_organizer.cli "D:\録画"                 # レポートのみ (ファイルは触らない)
py -m storage_organizer.cli "D:\録画" -r              # サブフォルダも対象
py -m storage_organizer.cli "D:\録画" --action copy   # 理由別フォルダにコピー
py -m storage_organizer.cli "D:\録画" --action move   # 理由別フォルダに移動
py -m storage_organizer.cli "D:\録画" --no-blur       # ぼやけ検出を省略して高速化
py -m storage_organizer.cli -h                        # しきい値の変更など全オプション
```

結果は `<フォルダ>\選別結果\` に出力されます。

## 構成
```
storage_organizer/
  video_analyzer.py   動画1本の解析と判定 (判定基準 Thresholds)
  files.py            ファイル探索・重複検出
  pending_folder.py   デスクトップの「削除予定」フォルダ作成と移動
  video_cleanup.py    削除候補スキャン・推奨度・サムネイル・移動履歴
  ffmpeg.py           ffmpeg / ffprobe の検出と実行
  cli.py              コマンドライン版
  web/server.py       画面用ローカルサーバー
  web/static/         画面 (HTML / CSS / JavaScript)
tests/                テスト
```

## テスト
```
py -m unittest discover -s tests -t .
```
`tests/test_with_ffmpeg.py` は ffmpeg でテスト用動画を生成して判定と画面APIを確かめます (ffmpeg が無ければスキップ)。
