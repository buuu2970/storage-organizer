# 録画・画像の整理支援アプリ（RecSort AI 試作版）

パソコンに溜まった録画や画像のうち、どれを整理すればよいかを支援する Windows 向けデスクトップアプリです。
起動すると **PC内の画像・動画を自動で探し**、「なぜ整理候補なのか」の理由とプレビューを表示します。
残すかどうかはユーザーが判断し、確認したうえで **Windows のごみ箱へ移動** できます。

- 自動で行うのは調査と候補の提示まで。自動削除はしません
- 完全削除はしません。ごみ箱へ移動できない場合はエラーにします
- 元ファイルを外部へアップロードしません（ネットワーク通信を行いません）
- 内容の面白さや大切さは解析していないため、「不要」「AIが不要と判断」とは表示しません

## 動作環境

- Windows 10 / 11、Python 3.12 以上
- ライブラリ: PySide6（画面・動画再生）、numpy（特徴量）、Pillow（画像の読み込み・類似判定・撮影日時）
- FFmpeg（ffmpeg と ffprobe）: 動画の長さ・録画日時・サムネイル・真っ暗な録画の判定などに使用。
  ない場合も画像の機能やスキャンは使えます（動画の解析だけが止まり、画面に案内が出ます）

## インストールと起動

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
winget install Gyan.FFmpeg
python main.py
```

FFmpeg を入れたらコマンドプロンプトを開き直してください。winget が使えない場合は
https://www.gyan.dev/ffmpeg/builds/ から zip を展開し、アプリの「設定」で `bin` フォルダを指定します。

## 使い方

1. 起動すると自動で調査が始まります（フォルダを選ぶ必要はありません）。見つかったものから順に表示されます
2. 左の「重複」「類似画像」「録画確認候補」「大容量」などで、理由別に候補を確認します
3. 右側でプレビュー・詳細・理由を見て「残す」「削除候補」「保留」「絶対に残す」を選びます
4. 「削除候補をごみ箱へ移動…」で、ファイル名・保存場所・件数・合計容量を確認して実行します

動作確認用のサンプル動画（合成映像のみ）は、次のコマンドでビデオフォルダに作れます。次回の起動時（または「再スキャン」）で見つかります。

```
python tools/make_sample_videos.py %USERPROFILE%\Videos\recsort_sample
```

## 画面

| 場所 | 内容 |
|---|---|
| 左 | 整理: すべて・重複・類似画像・録画確認候補・大容量・保護・保留・削除候補。その下に動画AI（試作）の画面と設定 |
| 上 | 調査中の場所・検出件数・検出した容量、一時停止／再開・キャンセル・再スキャン、調査範囲、容量の内訳 |
| 中央 | サムネイル一覧。並べ替え: 容量・撮影/録画日時・更新日時・動画時間・1分あたりの容量・見返していない順 |
| 右 | 1件のプレビュー（画像・動画再生）と詳細・候補の理由。重複・類似は横並びの比較画面 |

## 自動スキャン

- 優先順: ピクチャ → ビデオ → ダウンロード → デスクトップ → ドキュメント → 内蔵ドライブ全体
- ユーザーフォルダの実際の保存先は Windows（既知フォルダ API）から取得します。OneDrive に移動されていても追跡します
- 外付け・ネットワーク・種類を判別できないドライブは自動では調べません。設定の「追加で調べる場所」で追加できます
- 除外: Windows・Program Files・ProgramData などのシステム領域、AppData・キャッシュ・一時フォルダ、隠しフォルダ、
  ドライブ全体の調査で実行ファイルを含むアプリのフォルダと 10KB 未満の画像、設定で指定したフォルダ
- リンク・ジャンクションはたどりません（循環・二重集計の防止）。同じ場所を複数の調査場所で重ねて調べません
- アクセスできない場所はスキップし、「調査範囲…」で一覧できます。管理者権限は不要です
- オンライン専用ファイルは一覧に表示しますが、中身は読みません（自動ダウンロードしない）。解析・ハッシュ計算・プレビュー・ごみ箱への移動の対象外です
- 全体の件数は調べ終わるまで分からないため、調査中は割合や残り時間を表示しません
- 除外範囲があるため、「PC内のすべてを確認済み」とは表示しません
- 2回目以降は前回の結果をすぐ表示し、バックグラウンドで更新します。サイズ・更新日時が変わったファイルだけ解析し直し、ハッシュ値とサムネイルはキャッシュします
- 判断（残す・削除候補・保留）と「絶対に残す」は次回以降も保持します

## 候補の種類

| 候補 | 判定方法 |
|---|---|
| 完全重複 | サイズが同じファイルだけ SHA-256 を計算し、内容の一致でまとめる（名前だけでは判定しない）。1つを「残すおすすめ」に |
| 類似画像 | 知覚ハッシュ（dHash）が近い画像をまとめる（縮小・再圧縮・軽い編集など）。完全一致とは区別して表示し、解像度が最も高いものを「残すおすすめ」に |
| 録画確認候補 | 3秒未満の動画、確認した3場面がほぼ真っ暗な動画、読み込みエラー、破損を確認したもの（0バイト・画像の途中切れ・動画の索引情報がない）。読み込みエラーは「破損とは限らない」と表示 |
| 大容量 | 100MB 以上。動画は再生時間と1分あたりの容量も表示（これだけでは整理候補にしない） |

撮影・録画日時が取得できない場合は、更新日時で代用せず「不明」と表示します。
「見返していない順」は、このアプリで確認した日時だけを使います（記録開始より前は不明として扱います）。

## 目標容量からの提案とごみ箱への移動

- 「目標容量から提案…」で「20GB」などを指定すると、整理候補（重複分・類似のおすすめ以外・録画確認候補）から目標に近い組み合わせを提案します。
  チェックを変えると見込みの空き容量が更新されます。候補が足りない場合は、ほかのファイルを足さずに不足分を表示します
- 「絶対に残す」「残す」と判断したもの、大容量という理由だけのものは提案に含めません
- 初期状態では何も削除候補にしていません
- ごみ箱へ移動する直前に、スキャン時からファイルが変更されていないかを確認します。変わっていたら移動しません
- 内容が同じファイルがすべて対象になっている場合は、残すおすすめの1つを移動しません
- Windows の SHFileOperation でごみ箱へ移動します。ドライブにごみ箱がない場合は事前に止め、Windows が完全削除しようとした場合は警告で止められます
- ごみ箱へ移動しただけでは空き容量は増えません（ごみ箱を空にすると増えます）

## 動画AI（試作）の3つのAI

| AI | 役割 | 教師データ |
|---|---|---|
| ジャンル分類AI | 動画のジャンルを予測（複数可）。不確かなら未分類 | ユーザーが確定したジャンル |
| ジャンル別厳選AI | ジャンルごとに「残す候補／整理候補／保留」を提案 | ジャンル別厳選での回答（ジャンルごとに独立） |
| 全動画厳選AI | ジャンルに関係なく保存基準を提案 | 全動画厳選での回答だけ |

- 3つのAIは教師データとモデルを分けて持ち、互いの回答を混ぜません。厳選AIの特徴量にジャンルは含めません
- 厳選AIは「残す」「整理候補」がそれぞれ2件以上集まった学習範囲だけ学習し、足りない範囲は「保留」と表示します
- ジャンル別厳選では、動画が属する選択ジャンルのAIだけで判定し、すべて一致したときだけ提案します。判定が分かれたり、判定できないジャンルがあると「保留」です
- 複数ジャンルに属する動画への回答は、ボタン1回で対象ジャンルすべてに記録します（共通回答）。右側の欄でジャンルごとに変えることもでき（個別回答）、個別回答は共通回答より優先されます
- 「保留」は教師データに使いません。同じ動画・同じ学習範囲で有効な回答は1つで、以前の回答は履歴として残します
- 動画のジャンルを追加・削除すると、そのジャンルの回答は「再確認待ち」になり、確認するまで学習に使いません（別のジャンルへ自動で移しません。全動画厳選の回答は影響を受けません）
- 再学習はボタンを押したときだけ行い、教師データに変更があった学習範囲だけを作り直します。作れなかった場合は以前のモデルを使い続けます
- 学習リセットでは、AIを選んでモデルだけを未学習状態に戻します。教師データ・回答履歴・動画・ジャンル設定・お気に入り・保護設定は変更しません。ジャンル分類AIは明示的に選んだときだけリセットします
- 「整理推薦」（保護対象・重複確認・圧縮候補・内容確認）は客観的な情報で、厳選AIの提案とは別の列に表示します

整理推薦は「保護対象 ＞ 重複確認 ＞ 圧縮候補 ＞ 内容確認」の順でメイン判定を1つ決め、他に該当する条件は追加候補として併記します。

## AI の実装範囲

| 区分 | 内容 |
|---|---|
| 実装済み | 映像の数値特徴（明るさ・黒画面率・静止率・動き・輪郭・色）、音声の数値特徴（音量・無音率・ゼロ交差率・スペクトル）、長さ・解像度などのメタデータ |
| 実装済み | 教師データとの類似度による複数ジャンル推定（最近傍法）。根拠が弱いときは「未分類」として理由を表示 |
| 実装済み | 手動の再学習、以前のモデルの保持、1件ずつ外して予測する方式（leave-one-out）での評価 |
| 実装済み | 測定値から判断できるタグ候補（黒画面・静止画が多い・無音区間が多い・長時間）の提案と、採用・却下・保留 |
| 実装済み | ジャンル別厳選AI・全動画厳選AI（回答した動画との類似度。数値特徴・ファイルサイズ・経過日数を使用） |
| 試作の判定 | 上記の類似度は「数値の傾向が似ている」ことしか表しません。教師データが少ない段階の評価値は参考値です |
| 未実装 | 音楽・歌唱・会話の意味分類、字幕判定、事前学習済みモデル（CLIP・CLAP など） |

- 「その他・不明」は中身がばらばらなので、学習のクラスにしていません（負例としてのみ使います）
- 手動で付けたジャンルは AI が上書きしません
- 動画の内容を外部へ送信する処理はありません（このアプリはネットワーク通信を行いません）

## 将来の拡張（未実装・計画）

| 機能 | 実現方法 | 依存関係 | 処理負荷 |
|---|---|---|---|
| 一定間隔のサムネイル | FFmpeg で 10〜30 秒ごとに1枚を書き出し、タイムラインに並べる。キャッシュに保存 | FFmpeg（導入済み） | 1時間の録画で数十枚。シークで取り出せば数十秒程度 |
| 似た動画・同じ場面の比較 | 上のサムネイルごとに dHash を作り、場面単位で一致を数える | Pillow（導入済み） | 動画数×場面数の比較。区切り方式（今の類似画像と同じ）で絞り込む |
| ハイライト候補の抽出 | 場面の変化量（映像の差分）と音量の変化から、変化の大きい区間を候補にする | FFmpeg・numpy（導入済み） | 長い録画は音声を全編読む必要があり、1時間で数分程度 |
| 選んだ場面の書き出し | FFmpeg の `-ss` と `-to` で別ファイルに書き出す。元動画は読むだけ | FFmpeg（導入済み） | 再エンコードなし（`-c copy`）なら数秒。正確な位置で切るには再エンコードが必要 |

画像のぼけ判定（ラプラシアンの分散など）と、動画の無音判定（音声の音量）も追加機能として検討中です。

## 注意点

- データはアプリ専用のフォルダ（`%LOCALAPPDATA%\RecSortAI`）に保存します。サムネイルなどのキャッシュもここに作ります
- 以前の版のデータベースは、起動時に自動で新しい形式へ移行します

## 既知の制限

- 外付けドライブの判別（接続方式の取得）と既知フォルダの取得は Windows の API を使うため、Windows 実機でだけ動作します。
  開発環境（Linux）では、テスト用の場所に差し替えて確認しています
- ハードリンク（同じ実体を指す別名）は、件数・容量の集計では別ファイルとして数えます
- 類似画像は構図の似た画像をまとめるため、色だけが違う同じ構図の画像も「類似」になることがあります
- 画像の一覧はサムネイルを必要になった時点で作るため、初回はサムネイルの表示に時間がかかります
- HEIC・RAW などは一覧に表示しますが、プレビュー・類似判定はできません
- 一度に表示する一覧が非常に多い場合（数十万件）、表示の更新に時間がかかることがあります
