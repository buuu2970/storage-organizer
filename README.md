# RecSort — 録画の整理

Windows PC を調べて、何が容量を使っているかを示し、特に **完全一致の重複** と **解像度・圧縮が違う類似録画** を整理候補として提案するデスクトップアプリです（Python + PySide6）。
似た録画を並べて比較し、納得して残す1本を選んでから、Windows のごみ箱へ移します。

- 提案は決まったルールによるもので、AI による判定ではありません。機械学習は使いません
- 自動削除・完全削除はしません。ごみ箱を自動で空にしません
- データベースは使いません（設定・保護・判断は JSON）
- 個人の録画やファイル情報を外部へ送信しません

バージョン: 0.9.0rc2（リリース候補）。配布手順は `DISTRIBUTION.md`、ライセンスは `THIRD_PARTY_NOTICES.md`、作業記録は `RELEASE_CHECKLIST.md`。

## 使い方（ホーム → 候補を確認 → 比較して選ぶ → 最終確認 → 結果）

1. ホームの「PCを調べる」で、調べる範囲（ドライブ全体・フォルダ）を確認して調査を始めます。調査中も操作でき、一時停止・キャンセルできます
2. ホームで、ドライブの空き容量、何が容量を使っているか、おすすめ（重複・類似録画のグループと代表画像）を確認します
3. 「比較して選ぶ」で録画を横に並べ、同じ相対時点（長さの 20/40/60/80%）の場面、長さ・解像度・容量を比べます。「これを残す」「すべて残す（両方残す）」「保留」「再生」が使えます
4. 「候補を確認」では全グループを一覧できます。目標容量（今より○GB 追加で空けたい）とドライブを指定すると、目標に合わせて提案します（任意）
5. 「最終確認」で、ごみ箱へ移すファイルと残すファイル、件数と合計サイズを確認して移動します。戻って選び直せます
6. 「結果」で、移動・スキップ（安全確認で止めた）・失敗を分けて確認し、次の候補へ進みます

ごみ箱へ移しただけでは空き容量は増えません。ごみ箱を空にすると増えます。

## 提案のルール

| 種類 | 判定 | 扱い |
|---|---|---|
| 完全重複 | サイズで絞り、ファイル全体の SHA-256 で一致を確認 | 各グループで必ず1本を残す（保護したもの → なければ最も古いもの）。提案どおり選択済み |
| 類似録画 | 長さがほぼ同じで、代表場面の大半が一致（下記） | 同じ内容とは保証しない。比較して残す1本を確定するまで選べず、ごみ箱へも移せない |
| 要確認 | 失敗した可能性・500MB 以上・1年以上更新なし | 目標容量を指定し、重複と類似で足りないときだけ追加。未選択 |

- 保護・「残す」・保留・オンライン専用のファイルは対象外。システムやアプリの領域は候補にせず、「容量の内訳」で Windows の設定へ案内します
- 目標を満たすために基準を緩めたり、根拠のない候補を足したりしません。足りなければ不足分を表示します
- 同じファイル（別の表記・ハードリンク）を二重に数えません。完全重複のコピーは類似グループに重ねて入れません
- 別のドライブの録画は、目的のドライブの解放見込みに含めません
- 解像度やビットレートだけで「高画質」と断定しません。明確な優劣がない類似録画には、残すおすすめを付けません

## 類似録画の判定

長さが近い動画（差 1.5 秒以内または 2% 以内）どうしだけ、同じ相対時点の 12 場面を 32×18 の白黒画像にして比べます。黒画面・単色の場面は判定に使わず、情報のある場面の 75% 以上が一致（相関 0.85 以上）したときだけ類似とします。グループは全員どうしが類似のときだけまとめ、連鎖的な混入を防ぎます。代表場面はファイルが変わるまで再利用します。
検証結果は `RELEASE_CHECKLIST.md`、検証スクリプトは `tools/eval_similar.py`。

## データの保存（データベースは使わない）

保存先: `%LOCALAPPDATA%\RecSort`（開発用の環境変数 `RECSORT_DATA_DIR` で変更可）

| ファイル | 内容 |
|---|---|
| settings.json | 設定 |
| user_state.json | 保護・判断（パスごと） |
| scan_state.json | 調査場所・スキップ・容量の集計・類似グループ |
| inventory/*.json.gz | 見つけた画像・動画の一覧（場所ごと。場所の調査が終わるたびに書き出す） |
| analysis.jsonl | ハッシュ・解析結果（追記のみ。壊れた行は読み飛ばし、大きくなったら起動時に整理） |
| trash_log.jsonl | ごみ箱への移動の記録 |
| thumbs/ | サムネイル・比較用の場面（上限 300MB） |
| logs/ | エラーログ（ホームフォルダのパスは伏せる） |

JSON は一時ファイルに書いてから置き換えるので、書き込み中に落ちても壊れません。壊れたファイルは退避して既定値で起動します。
以前の版（`%LOCALAPPDATA%\RecSortAI\recsort.db`）がある場合は、設定画面の「以前の版の設定・保護・判断を取り込む」で移行できます（このときだけ SQLite を読み取り専用で開きます。旧 DB は削除しません）。

- Windows 10 / 11（主な対象は Windows 11）、Python 3.12 以上（ソースから起動する場合）
- FFmpeg（ffmpeg・ffprobe）: 類似録画の判定・録画の長さ・プレビュー画像に必要。ない場合も重複の検出と容量の集計はできます

```

.venv\Scripts\activate
pip install -r requirements.txt

python main.py
```

動作確認用のサンプル動画（合成映像のみ）: `python tools/make_sample_videos.py %USERPROFILE%\Videos\recsort_sample`

## 既知の制限

- Windows 固有の部分（既知フォルダ・ドライブ種別・ごみ箱 API・表示倍率・配布版 exe）は、開発環境（Linux）では確認できていません
- 類似判定の検証は合成映像のみ。実際のゲーム録画などでの精度は未確認です。長さが違う・編集・切り抜き・部分的に重なる動画は対象外です
- 容量はファイルサイズ（論理サイズ）の合計です。実際のディスク占有量は取得していません
- システム・アプリの領域の容量は、読み取れる範囲で測った値です（権限のない場所は含みません）
- 「要確認」の基準（500MB・1年）は固定です。視聴したかどうかは分かりません
- ごみ箱からの復元は Windows のごみ箱で行います（アプリに復元機能はありません）
