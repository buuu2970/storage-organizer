# RecSort AI（試作版）

録画ファイルの整理を支援する Windows 向けデスクトップアプリの試作品です。
フォルダをスキャンして容量を調べ、動画のジャンル分類・厳選・重複検出・圧縮を試せます。
学校のメンバーが操作して、機能や AI の判定方法を検討するためのものです。

**ファイルの削除は一切行いません。** 元の動画は読み取るだけで、変更・上書きしません。

## 動作環境と必要なもの

- Windows 10 / 11
- Python 3.12 以上
- ライブラリ: PySide6（画面・動画再生）、numpy（特徴量の計算）
- FFmpeg（ffmpeg と ffprobe）: 解析・サムネイル・圧縮に使用。なくても、スキャン・一覧・ジャンル管理・重複検出などは使えます

## FFmpeg の導入

次のどちらかで導入します。

**winget を使う場合（簡単）**

```
winget install Gyan.FFmpeg
```

インストール後、コマンドプロンプトを開き直して `ffmpeg -version` が表示されれば完了です。

**手動の場合**

https://www.gyan.dev/ffmpeg/builds/ などから zip をダウンロードして展開し、
アプリの「設定」画面で `ffmpeg.exe` と `ffprobe.exe` がある `bin` フォルダを指定してください。

## インストール

このフォルダで、コマンドプロンプトから実行します。

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 起動

```
python main.py
```

## 試し方

1. サンプル動画を作る（FFmpeg の合成映像・音声だけで作るので、共有しても問題ありません）
   ```
   python tools/make_sample_videos.py %USERPROFILE%\sample_videos
   ```
2. アプリの「ファイル調査」で `sample_videos` フォルダをスキャンする
3. 初期学習の案内が出たら「初期学習を開始」を選び、5本にジャンルを付けて「完了して学習する」
4. 「動画一覧」「未分類動画」「厳選」「重複グループ」「圧縮」を操作する

## 主な機能

| 画面 | 内容 |
|---|---|
| ダッシュボード | 登録数・解析状況・AI モデルの状態・FFmpeg の有無 |
| ファイル調査 | フォルダをサブフォルダまでスキャンし、全ファイルを容量順で表示（従来の機能）。動画はデータベースに登録 |
| 動画一覧 | サムネイル・ジャンル・タグ・お気に入り・保護・AI判定・整理推薦。検索・絞り込み・並び替え |
| 動画詳細 | 異なる場面のサムネイル3枚、再生・停止・シーク、ジャンル・タグ編集、お気に入り・保護、重複情報、AI の判定理由 |
| ジャンル管理 | ジャンル・タグの追加・名前変更・削除（削除は確認あり。内部 ID で管理） |
| 初期 AI 学習 | 特徴の異なる動画を最大5本選び、ジャンルを付けて学習。スキップ可能 |
| 未分類動画 | AI が判断できなかった動画をまとめて分類。手動の「再学習」で反映 |
| 厳選 | ジャンル別（複数選択・OR 条件）と全動画。「残す／整理候補／保留」を記録（削除はしない）。厳選AIの提案と理由を表示 |
| 再確認待ち | ジャンル変更で学習から一時的に外したジャンル別の回答を確認・修正して戻す |
| 重複グループ | サイズで絞ってから SHA-256 で完全一致を検出。重複分の容量を表示 |
| 圧縮 | 3つのプリセットで別ファイルに出力。保護中は不可。前後の容量表示と再生確認 |
| 設定 | FFmpeg の場所、映像の最大抽出枚数、初期学習のリセット、学習リセット |

## 3つのAI

| AI | 役割 | 教師データ |
|---|---|---|
| ジャンル分類AI | 動画のジャンルを予測（複数可）。不確かなら未分類 | ユーザーが確定したジャンル |
| ジャンル別厳選AI | ジャンルごとに「残す候補／整理候補／保留」を提案 | ジャンル別厳選での回答（ジャンルごとに独立） |
| 全動画厳選AI | ジャンルに関係なく保存基準を提案 | 全動画厳選での回答だけ |

- 3つのAIは教師データとモデルを分けて持ち、互いの回答を混ぜません。厳選AIの特徴量にジャンルは含めません
- 厳選AIは「残す」「整理候補」がそれぞれ2件以上集まった学習範囲だけ学習し、足りない範囲は「保留」と表示します
- ジャンル別厳選では、動画が属する選択ジャンルのAIだけで判定し、すべて一致したときだけ提案します。判定が分かれたり、判定できないジャンルがあると「保留」です
- 複数ジャンルに属する動画への回答は、ボタン1回で対象ジャンルすべてに記録します（共通回答）。右側の欄でジャンルごとに変えることもでき（個別回答）、個別回答は共通回答より優先されます
- 「保留」は教師データに使いません。同じ動画・同じ学習範囲で有効な回答は1つで、以前の回答は履歴として残します
- 動画のジャンルを追加・削除すると、そのジャンルの回答は「再確認待ち」になり、確認するまで学習に使いません（別のジャンルへ自動で移しません。全動画厳選の回答は影響を受けません）
- 再学習はボタンを押したときだけ行い、教師データに変更があった学習範囲だけを作り直します。作れなかった場合は以前のモデルを使い続けます
- 学習リセットでは、AIを選んでモデルだけを未学習状態に戻します。教師データ・回答履歴・動画・ジャンル設定・お気に入り・保護設定は変更しません。ジャンル分類AIは明示的に選んだときだけリセットします
- 「整理推薦」（保護対象・重複確認・圧縮候補・内容確認）は客観的な情報で、厳選AIの提案とは別の列に表示します

整理推薦は「保護対象 ＞ 重複確認 ＞ 圧縮候補 ＞ 内容確認」の順でメイン判定を1つ決め、他に該当する条件は追加候補として併記します。

## AI の実装範囲

| 区分 | 内容 |
|---|---|
| 実装済み | 映像の数値特徴（明るさ・黒画面率・静止率・動き・輪郭・色）、音声の数値特徴（音量・無音率・ゼロ交差率・スペクトル）、長さ・解像度などのメタデータ |
| 実装済み | 教師データとの類似度による複数ジャンル推定（最近傍法）。根拠が弱いときは「未分類」として理由を表示 |
| 実装済み | 手動の再学習、以前のモデルの保持、1件ずつ外して予測する方式（leave-one-out）での評価 |
| 実装済み | 測定値から判断できるタグ候補（黒画面・静止画が多い・無音区間が多い・長時間）の提案と、採用・却下・保留 |
| 実装済み | ジャンル別厳選AI・全動画厳選AI（回答した動画との類似度。数値特徴・ファイルサイズ・経過日数を使用） |
| 試作の判定 | 上記の類似度は「数値の傾向が似ている」ことしか表しません。教師データが少ない段階の評価値は参考値です |
| 未実装 | 音楽・歌唱・会話の意味分類、字幕判定、事前学習済みモデル（CLIP・CLAP など） |

- 「その他・不明」は中身がばらばらなので、学習のクラスにしていません（負例としてのみ使います）
- 手動で付けたジャンルは AI が上書きしません
- 動画の内容を外部へ送信する処理はありません（このアプリはネットワーク通信を行いません）

## 注意点

- データはアプリ専用のフォルダ（`%LOCALAPPDATA%\RecSortAI`）に保存します。動画ファイル自体は保存しません
- ファイルのサイズや更新日時が変わった動画は、古い解析結果を自動で無効にします
- クラウド上のみのファイル（OneDrive のオンライン専用ファイルなど）は、解析・ハッシュ計算・圧縮のために読み込みません
- 解析・ハッシュ計算・圧縮は、処理の前後でファイルの状態を比べ、途中で変わった場合は結果を使いません
- 圧縮しただけでは容量は空きません（元の動画は残ります）
- スキャンで見つからなくなった動画は一覧に表示しなくなりますが、記録は残します

## 既知の制限

- 解析は動画1本あたり、抽出枚数に応じて数秒〜数十秒かかります（設定で抽出枚数を減らせます）
- 音声の解析は、動画内の最大12か所（各3秒）を抜き出して行います。全編の無音検出ではありません
- 一度に実行できる重い処理（解析・重複検出・再学習・圧縮）は1つだけです
- 動画プレビューは Qt Multimedia を使います。対応していない形式は、詳細画面に再生エラーとして表示します
- 削除機能はありません
- 以前の版の厳選結果は、最初の起動時に全動画厳選の回答として引き継ぎます
- ジャンル別厳選で記録できるのは、ジャンルを確定した動画だけです（AIの分類だけで対象になった動画には記録しません）
- 学習リセットで初期化するのはモデルだけです。教師データ・回答履歴の削除機能はまだありません

## テスト

```
python -m unittest discover -s tests -v
```

FFmpeg がない環境では、解析・圧縮のテストは自動でスキップします。GUI のテストではウィンドウが一瞬表示されます。
